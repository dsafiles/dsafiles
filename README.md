# DSA Files

[DSA Files](https://dsafiles.com/) is a citation-first public research project about the Democratic Socialists of America, related organizations, people, and events.

This repository is the public research library and the profile home for the project. The research is written to be read, downloaded, checked, corrected, and improved.

## Public research

- [DSA Founding Convention](events/2026-08-02-DSA-Founding-Convention.md)

The website presents reviewed research as readable pages. Chat citations link to the exact relevant section on the website. Footnotes then link to the original evidence.

## Contribute

Corrections and contributions are welcome through GitHub issues and pull requests. Read [CONTRIBUTING.md](CONTRIBUTING.md) and [RESEARCH.md](RESEARCH.md) first.

Pull requests are public as soon as they are opened. Do not submit private information, credentials, downloaded source files, or material that cannot lawfully be redistributed.
